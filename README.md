# 발주서 정리 일꾼 (po-normalizer)

거래처마다 모양이 다른 발주서를 **우리 양식 한 장**으로 정리해 주는 Claude 에이전트 스킬입니다.
엑셀, CSV, 메일 본문, PDF, 팩스·사진 어느 것이 와도 같은 양식의 엑셀로 바꿔 줍니다.

> 여기 있는 회사 이름, 품목, 금액, 연락처는 모두 **가짜(샘플)** 입니다.

## 이 일꾼의 약속
- **원본에 있는 값만 옮깁니다.** 빈 단가나 애매한 납기를 짐작해서 채우지 않습니다.
- **모르면 '확인 필요'** 로 표시하고, 왜 그런지 원본 문장과 함께 따로 모아 줍니다.
- **금액은 검산합니다.** 수량 × 단가가 원본 금액과 다르면 알려 줍니다.

## 어떻게 일하나요
```
제각각인 발주서  →  ① Claude가 읽고 칸 맞추기  →  정리값.json  →  ② make_po.py  →  우리양식 엑셀
(엑셀·CSV·메일·PDF·사진) (SKILL.md 지침대로)                       (검산·확인 필요 표시)
```
- ①은 사람이 읽듯 유연해야 해서 **Claude**가 합니다 (열 이름이 달라도, 문장으로 써 있어도 OK).
- ②는 틀리면 안 되는 일이라 **코드**가 합니다 (계산, 빈칸 표시, 양식 채우기).

## 샘플로 확인한 결과
| 샘플 | 모양 | 일부러 넣은 문제 | 결과 |
|---|---|---|---|
| 01 가나상사 | 엑셀, 위에 회사 정보, 열 이름·순서 다름 | 없음 (깨끗한 예) | 확인 필요 0건, 합계 186,000원 |
| 02 다라테크 | CSV, 영어 머리글, 미국식 날짜 | 단가 빈칸("협의중"), 납기 빈칸, 담당자 정보 없음 | 확인 필요 9건 |
| 03 마바산업 | 메일 본문 | "다음 주 금요일쯤", "단가는 지난번이랑 같게", 발주번호 없음 | 확인 필요 6건 |
| 04 사아물산 | PDF | 2번 품목 금액이 수량×단가와 다름 (460,000 vs 440,000) | 확인 필요 2건 |
| 05 자차상회 | 팩스를 찍은 사진(JPG), 살짝 기울고 흐림 | 수량 칸 하나가 얼룩으로 가려짐, 단위 없음, "결제: 기존 조건과 동일" | 확인 필요 5건, 합계 774,000원 (원본 합계와 일치) |

> 05번처럼 사진이나 스캔본도 Claude가 직접 보고 읽습니다. 가려진 수량은 금액÷단가로 80이라고 짐작할 수 있지만, **원본에 보이는 숫자가 아니라서 채우지 않고** '확인 필요'로 남깁니다.

결과 엑셀은 `정리완료/2026-11/` 폴더에 있습니다. '확인 필요' 칸은 노란 바탕에 빨간 글씨이고, **확인 필요** 탭에 이유가 정리돼 있습니다.

### 결과 화면 예시 1: 메일로 온 발주 (마바산업)
원본은 표 없이 문장으로 쓴 메일입니다.
> 2) 샘플 스프링 - 800개, **단가는 지난번이랑 같게** 해주세요
> 납기는 **다음 주 금요일쯤**이면 좋겠고요, 늦어도 12월 초까지는 꼭 부탁드립니다.

일꾼은 이 문장들을 짐작으로 채우지 않고 '확인 필요'로 남깁니다.

![마바산업 결과 - 발주서 탭](이미지/마바산업_결과_발주서.png)

**확인 필요** 탭에는 원본 문장과 이유가 함께 정리돼서, 그대로 거래처에 물어보면 됩니다.

![마바산업 결과 - 확인 필요 탭](이미지/마바산업_결과_확인필요.png)

### 결과 화면 예시 2: PDF 발주서 (사아물산)
2번 품목의 원본 금액(460,000원)이 수량 × 단가(400 × 1,100 = 440,000원)와 다릅니다.
일꾼은 어느 쪽이 맞는지 고르지 않고 '확인 필요'로 표시합니다.

![사아물산 결과 - 발주서 탭](이미지/사아물산_결과_발주서.png)

![사아물산 결과 - 확인 필요 탭](이미지/사아물산_결과_확인필요.png)

## 사용법
### 방법 1. Claude에게 맡기기 (추천)
1. 이 폴더를 Claude Code 프로젝트나 Claude 스킬 폴더에 넣습니다.
2. 발주서 파일을 주고 이렇게 말합니다: **"이 발주서 우리 양식으로 정리해줘"**
3. Claude가 `SKILL.md`대로 읽고, 정리하고, 결과 엑셀과 확인할 질문을 줍니다.

**대화 예시**
> **나:** 사아물산에서 PDF로 발주서 왔어. 우리 양식으로 정리해줘.
>
> **Claude:** 3개 품목 정리했어요. 확인 필요 2건이 있어요.
> - 2번 품목(샘플 부싱) 금액: 원본 460,000원인데 수량×단가는 440,000원이에요. 어느 쪽이 맞는지 사아물산에 물어봐 주세요.
> - 그래서 합계도 아직 확정할 수 없어요. (아는 금액만 더하면 1,300,000원)
>
> 저장: `정리완료/2026-11/20261119_사아물산_SA-2026-0451_v1_확인필요2건.xlsx`

### 방법 2. 직접 실행하기
```
pip install openpyxl
python make_po.py 예시_결과/04_사아물산_정리값.json
```
저장 위치와 파일 이름은 아래 저장 규칙대로 자동으로 정해집니다.

## 저장 규칙과 버전 관리
결과는 **정해진 곳에, 정해진 이름으로, 덮어쓰지 않고** 저장됩니다.

| | 규칙 |
|---|---|
| 저장 위치 | `설정.json`의 `저장폴더` (기본: `정리완료/`). 그 아래 **월별** 폴더(`2026-11/`)로 나눔. `거래처별`, `없음`으로 바꿀 수 있음 |
| 파일 이름 | `발주일_거래처_발주번호_v버전_확인필요N건.xlsx` (확인할 게 없으면 `_확인필요` 부분이 빠짐) |
| 버전 | 같은 발주서를 다시 정리하면 v1 → v2 → v3. **지난 버전은 그대로 남음** |
| 작업기록 | `정리완료/작업기록.csv`에 언제, 어떤 원본으로, 몇 번째 버전을, 확인 필요 몇 건으로 만들었는지 한 줄씩 쌓임 |

**버전이 바뀌는 예 (마바산업)**
```
20261118_마바산업_번호없음_v1_확인필요6건.xlsx   ← 처음 정리 (메일만 보고)
20261118_마바산업_번호없음_v2_확인필요1건.xlsx   ← 거래처 답장(가상)으로 납기·단가·결제조건 확인 후
```
v2에는 아직 발주번호 1건이 남아 있어서, 이름만 봐도 할 일이 남았다는 걸 알 수 있습니다.

`설정.json` 예:
```json
{ "저장폴더": "정리완료", "폴더나누기": "월별", "작업기록": true }
```

## 우리 회사 양식으로 바꾸려면
`우리양식_발주서.xlsx`의 모양(글꼴, 색, 로고)은 자유롭게 바꿔도 됩니다.
칸 위치를 옮겼다면 `make_po.py` 위쪽의 `HEAD_CELLS`(머리 정보 칸)와 `FIRST_ROW`(품목 시작 줄)만 맞춰 주세요.

## 폴더 구성
```
po-normalizer/
├─ README.md               ← 지금 보는 설명
├─ SKILL.md                ← 일꾼 업무 지침 (Claude가 읽음)
├─ make_po.py              ← 양식 채우기·검산·저장 코드
├─ 설정.json               ← 저장 폴더·폴더 나누기·작업기록 설정
├─ 우리양식_발주서.xlsx     ← 표준 양식
├─ 샘플_발주서/             ← 제각각인 가짜 발주서 5개
├─ 예시_결과/               ← 샘플별 정리값.json (마바산업은 답변 반영본 포함)
├─ 정리완료/                ← 저장 규칙대로 만든 결과 엑셀 + 작업기록.csv
└─ 이미지/                  ← README에 쓰는 결과 화면 사진
```

## 한계
- 사진·스캔본은 Claude가 눈으로 읽기 때문에, 흐리거나 가려진 글자는 '확인 필요'로 남깁니다. 사진에서 읽은 숫자는 원본과 한 번 더 대조해 주세요.
- 품목은 한 발주서당 20줄까지입니다 (양식 줄을 늘리면 더 가능).
- '확인 필요'를 채우는 건 사람 몫입니다. 일꾼은 무엇을 물어봐야 하는지만 알려 줍니다.
